# Volumetric-Atlas-Ensemble-VAE (VAE^2): Using 1D volumetric sMRI data to classify mental disorders 

Neuroimaging data interpretation remains challenging in psychiatric research due to lacking nosological understanding, structural heterogeneity, and confounding effects from multi-site datasets. This project addresses these challenges through a deep learning approach that can distinguish between psychiatric conditions while maintaining clinical interpretability. VAE^2 is a lightweight framework to classify mental disorders from sMRI data. It takes as input 1D volumetric data instead of 3D brain scans. Through a modular approach VAE^2 can leverage the strengths of mutliple segmentations (atlases) of each sample. This approach is highly flexible and even more lightweight, allowing for training and testing of your own models in mere minutes. Additionally, it has been validated that the latent space generated by VAE^2 does not only capture structural information specific to the diagnoses seen during training, but also general markers of disease and features closely linked to certain clinical rating scales.

## Folder Structure
To run the code the following folder structure is recommended, managing code, data and results:

* `analysis/`: This directory is dedicated to storing all the results generated from the analysis, including plots, metrics, and any other output files.
* `data/`: This folder is for housing all the input data required for the analysis, specifically the h5ad dataframes.
* `src/`: This directory contains all the Python scripts and source code for the implemented VAE models and analysis pipelines.

## Requirements

To run the deep learning models, a GPU with CUDA 11.6 is required for optimal performance. The code has been developed and tested with Python 3.10.8. Key Python package dependencies include:

* `scikit-learn==1.5.1`
* `torch==1.13.1`
* `scanpy==1.10.2`

A comprehensive list of all required packages can be found in the `requirements.txt` file.

## Running your own experiments 

- Clone this repository and cd into the directory
- Set up your experiment with the experiment_config.yaml and model_config.yaml files. 
- Ensure your data fits the required criteria (see below).
- Navigate to RUN_experiment.py and run your experiment. 


## Input / Output

The core idea is to train VAEs on 1-dimensional feature vectors derived from MRI data. These vectors represent Region of Interest (ROI) volumes, encompassing measurements of e.g. gray matter (GM), white matter (WM), and cerebrospinal fluid (CSF). For our own experiments the volume extraction was performed using the [CAT12 software](https://neuro-jena.github.io/cat12-help/), guided by four different atlases: [Neuromorphometrics](https://www.neuromorphometrics.com/), [LPBA40](https://www.loni.usc.edu/research/atlases), [COBRA](https://www.cobralab.ca/atlases), and [SUIT](https://www.diedrichsenlab.org/imaging/suit.htm).

### Input Data

The scripts accept either .h5 or .csv files as input. These dataframes are structured as follows:

* **Rows**: Represent individual Regions of Interest (ROIs) and measurement types. The index should strictly have the format ROI_mtype.
* **Columns**: Samples with unique samples names.

### Output Results

The analysis pipelines generate a variety of outputs to comprehensively evaluate model performance and interpret the learned representations:

* **Latent Space UMAP**: Visualizations of the latent space dimensionality reduction using UMAP during training, validation, and testing phases, offering insights into the separation of patient groups.
* **Performance Metrics**: Standard classification metrics including Precision, Accuracy, F1-Score, and Recall, reported to assess the overall performance of the models.
* **AUROC Values**: Single-class and multi-class Area Under the Receiver Operating Characteristic (AUROC) values, providing a robust measure of classification performance across different thresholds.
* **ROC Curves**: Visualizations of the Receiver Operating Characteristic (ROC) curves for each class label, illustrating the trade-off between true positive rate and false positive rate.
* **Correlation Heatmaps**: Heatmaps depicting the correlations between clinical variables and model predictions, aiding in the interpretability of the models' findings in a clinical context.
* **Feature Importance Analysis**: Saliency maps and SHAP (SHapley Additive exPlanations) values are computed to identify and quantify the importance of different input features (ROI volumes) in the model's decision-making process.
